# SS IPTV — тестовый EPG для BCU

Открытый репозиторий с **общедоступной программой передач**. Не загружайте сюда персональный M3U, IPTV-адреса потоков, логины, ключи или токены.

## Текущее состояние

- EPG источник: `input/epg-lite.xml.gz`, скачивается пользователем через браузер. Провайдер `bobor.pm` защищает архив интерактивной проверкой Cloudflare, поэтому GitHub Actions его **не скачивает автоматически**.
- `build_epg.py` оставляет **35 каналов BCU** с доступными передачами.
- GitHub Actions публикует `epg.xml` на GitHub Pages по адресу: https://tsvetkoff81.github.io/SS_IPTV_EPG/epg.xml
- `site/bcu-epg-test.m3u` — публичный диагностический плейлист из 6 записей BCU с **демонстрационным видеопотоком**, без персональных данных. **Он не заменяет настоящий IPTV-плейлист**.
- По состоянию на 18.10.2026 опубликовано 35 каналов, 1078 передач, XML ~181 КБ.
- Обновление EPG происходит по новому коммиту входного файла или ручному запуску GitHub Actions.

## Cloudflare Pages — дополнительная проверка CORS

Это **альтернативный бесплатный хостинг**, независимый от GitHub Pages. Он не требуется для сборки EPG. Добавлен только для проверки совместимости SS IPTV с заданными HTTP-заголовками.

В репозитории подготовлены:
- `site/_headers` — CORS-заголовки, включая `Range` и открытие заголовков ответа;
- `requirements.txt`, `build_cloudflare.sh` — сборка непосредственно из `input/epg-lite.xml.gz`;
- `prepare_cloudflare_m3u.py` — подставляет URL Cloudflare Pages в **безопасный демонстрационный** плейлист (Cloudflare автоматически предоставляет `CF_PAGES_URL`).

**Один раз подключить аккаунт вручную** (невозможно сделать только доступом к GitHub):

1. Откройте https://dash.cloudflare.com/ (нужен Cloudflare аккаунт с бесплатным тарифом).
2. **Workers & Pages → Create application → Pages → Import an existing Git repository**.
3. Разрешите GitHub интеграции Cloudflare читать **только** репозиторий `tsvetkoff81/SS_IPTV_EPG`; не выдавайте доступ к `Second-Brain`.
4. Выберите репозиторий `SS_IPTV_EPG`, ветку `main`, без framework preset.
5. **Build command:** `bash build_cloudflare.sh`
6. **Build output directory:** `site`
7. **Root directory:** корень репозитория (по умолчанию, не `site`).
8. Нажмите **Save and Deploy**.
9. После успеха Cloudflare покажет адрес проекта вида `https://<project>.pages.dev`. Проверить `<адрес>/epg.xml` и `<адрес>/bcu-epg-test.m3u`.

Cloudflare Pages автоматически запускает сборку при новых коммитах `main`, в том числе при обновлении файла EPG. Полный личный M3U и ключи IPTV не публикуются.

**Ограничения:**
- Cloudflare в сетях РФ может быть недоступен или замедлен; работоспособность на конкретном телевизоре ещё НЕ проверена.
- Pages может возвращать 200 вместо 206 на запрос Range; CORS-заголовки сами по себе не гарантируют совместимость приложения.
- Подключение личных каналов в корректном внешнем M3U — отдельная задача: сайт-публикатор **не должен раскрывать приватные потоковые адреса**.

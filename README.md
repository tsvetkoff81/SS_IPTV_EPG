# SS IPTV — тест телепрограммы BCU (без персональных ссылок)

Публичный репозиторий содержит открытые данные EPG, код обработки и **безопасный демонстрационный плейлист**. Никаких персональных потоковых ссылок, аккаунтов, паролей или ключей IPTV здесь нет.

## Проверенный результат

- Вручную загружен `input/epg-lite.xml.gz` (Cloudflare не пропускает GitHub Actions напрямую к bobor.pm).
- GitHub Actions распаковывает этот файл и **выбирает только 35 BCU XMLTV-каналов** (идентификаторы `Xbcu-...`).
- Подготовленный файл доступен по постоянному адресу: **https://tsvetkoff81.github.io/SS_IPTV_EPG/epg.xml**
- Обновление публикации срабатывает при замене архивного файла в `input/` или запуске workflow вручную. Автоматического скачивания с провайдера нет.
- Провайдерская программа по BCU Action/Comedy/Cinema в архиве от 18.10.2026 оканчивается вечером 18 октября; нельзя искусственно получить EPG на 2–3 дня вперёд.

## Проверка, может ли SS IPTV считывать внешний EPG

Тестовый внешний плейлист: **https://tsvetkoff81.github.io/SS_IPTV_EPG/bcu-epg-test.m3u**

В нём шесть тестовых записей: каналы BCU Action, Comedy, Cinema по два варианта привязки — `tvg-name` по отображаемому названию и по `XMLTV channel id`. В качестве видеопотока везде **публичный демонстрационный ролик Mux (Big Buck Bunny)**, а **не реальные телеканалы**. Это намеренно: проверяется появление расписания без публикации секретных ссылок в публичном GitHub.

Добавить URL через `SS IPTV → Настройки → Контент → Внешние плейлисты`, а затем открыть отдельную плитку с тестом. Полностью перезапустить приложение, если URL не обновился. Сначала посмотреть, появился ли EPG; воспроизведение демо-ролика не обязательно.

Если программа появилась у одного типа записей, для настоящего приватного плейлиста использовать именно этот вариант привязки. Если ни у одного — отдельно проверить HTTP-заголовки CORS GitHub Pages и поддержку XMLTV самой моделью телевизора.

**Важно:** этот M3U намеренно не содержит реальные ссылки BCU и не заменяет личный плейлист провайдера. Чтобы подключить программу к реальным BCU, понадобится отдельный **непубличный** URL персонального M3U, сохраняющий атрибут `x-tvg-url` и соответствия `tvg-name`. Внутренний редактор SS IPTV ранее удалял `x-tvg-url` при импорте.

## Обновление EPG

1. В браузере скачать `https://bobor.pm/epg/epg-lite.xml.gz`, пройти проверку Cloudflare.
2. Заменить `input/epg-lite.xml.gz` в публичном репозитории через Upload files → Commit changes.
3. Проверить запуск `Publish SS IPTV EPG` в GitHub Actions: `build` и `deploy` должны быть зелёными.
4. Телевизор получает XMLTV по прежней постоянной ссылке, если EPG совместим с устройством и заголовками сервера.

Документация SS IPTV: https://ss-iptv.com/ru/operators/epg

# SS IPTV — EPG обновляется вручную из файла провайдера

Публичный репозиторий содержит только общедоступную телепрограмму и список её каналов. Не размещайте здесь персональный IPTV-плейлист, ссылки потоков или ключи доступа.

## Как работает
1. В браузере скачать с сайта провайдера файл [epg-lite.xml.gz](https://bobor.pm/epg/epg-lite.xml.gz), пройдя обычную проверку Cloudflare.
2. Открыть папку [input](input) → **Add file** → **Upload files** → выбрать `epg-lite.xml.gz` → **Commit changes** в `main`.
3. Коммит файла `input/epg-lite.xml.gz` автоматически запускает [Publish SS IPTV EPG](../../actions/workflows/publish-epg.yml).
4. Скрипт `build_epg.py` читает сжатый XML, выбирает 766 идентификаторов телепрограммы из 14 выбранных категорий (в персональном M3U это 1 489 записей каналов), сокращает период и публикует `epg.xml` менее 4,5 МБ.
5. После успешных заданий `build` и `deploy` файл станет доступен по адресу **https://tsvetkoff81.github.io/SS_IPTV_EPG/epg.xml**.

**Сам GitHub Actions не обращается к серверу провайдера**: прямые запросы Python и PowerShell возвращают HTTP 403 (страница проверки Cloudflare). Нет автоматических бесполезных скачиваний и периодических запусков без нового файла.

## Ограничение периода

EPG с датой 18.10.2026 содержит программу для некоторых каналов до 25 октября, но для BCU Action/Comedy/Cinema расписание имеет начало только до 18 октября включительно. Скрипт не может добавить передачи, которых нет в исходном XML. Размер файла ограничен 4,5 МБ; для всех выбранных групп одновременно может вместиться менее двух полных дней. Период подбирается автоматически.

## Безопасность

- `input/epg-lite.xml.gz` и публикуемый `epg.xml` содержат программы передач, не IPTV-потоки.
- Файлы личного репозитория `Second-Brain` остаются закрытыми.
- **Никогда не добавлять персональный M3U** в этот публичный репозиторий.
- Не хранить в скрипте логины и пароли.

## SS IPTV

Для использования внешнего EPG приложение ожидает `x-tvg-url` в заголовке **непосредственно загружаемого внешнего M3U** и `tvg-name` для сопоставления программ с каналами. Редактор внутреннего плейлиста SS IPTV удаляет `x-tvg-url`, поэтому тест внешнего M3U проводится отдельно. Публикация XMLTV в GitHub Pages сама по себе не решает эту проблему.
